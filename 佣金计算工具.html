🎁 多奖励模式 二级/三级 · 维度独立开关

计算公式 首充佣金 = 命中首充人数档位对应金额 充值佣金 = 一级充值 × 一级比例 + 二级充值 × 二级比例 + 三级充值 × 三级比例 投注佣金 = 一级投注 × 一级比例 + 二级投注 × 二级比例 + 三级投注 × 三级比例 总佣金 = 启用的首充佣金 + 启用的充值佣金 + 启用的投注佣金
* 勾选“首充”会计入首充人数；最多二级时只统计 B、C 层，三级时继续统计 D 层。
💰 总佣金 = 0.00

🎯 有效投注模式 极差返佣 · 可视化树

* 示例规则：有效投注 < 10000 返佣 1%，有效投注 ≥ 10000 返佣 3%。
计算公式 A总业绩 = 层级范围内所有下级自身有效投注之和（不含A本人） A返佣比例 = A总业绩命中的阶梯返佣率 直属佣金 = 直属下级本人有效投注 × A返佣比例 其他佣金 = 直属下级下级总业绩 × max(A返佣比例 - 直属下级返佣比例, 0) A本期佣金 = 直属佣金 + 其他佣金

📉 净盈利模式 极差返佣 · 可视化树

* 净盈利 = 总输额 - 总赢额 - 优惠金额 - 平台成本；负数会降低上级总净盈利，佣金不倒扣。
计算公式 适用场景：佣金计算依据为“净盈利”时。 单个会员净盈利 = 会员总输额 - 会员总赢额 - 会员获得的总优惠金额 - 平台分摊成本 A总净盈利业绩 = 层级范围内所有下级自身净盈利之和（不含A本人） 直属佣金 = max(直属下级本人净盈利, 0) × A返佣比例 其他佣金 = max(直属下级总净盈利业绩, 0) × max(A返佣比例 - 直属下级返佣比例, 0) 直属下级贡献佣金 C = 来自该下级的直属佣金 + 来自该下级的极差佣金 若 C 超过返佣上限 L，只计入 L；优先截断其他佣金，再截断直属佣金 A本期佣金 = 截断后的直属佣金 + 截断后的其他佣金；净盈利为负时降低总业绩，但佣金不倒扣
