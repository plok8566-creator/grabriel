1. 功能概述

为了激励代理发展多级下线，提升平台有效投注量及盈利能力，系统需对现有代理模式进行升级。核心目标是支持无限层级代理，采用极差返佣模式，根据代理整体业绩（有效投注或净盈利）确定返佣比例，并通过与直属下级的比例差计算额外佣金。

本次需求主要包含以下三部分：

  1. 新增代理模式：支持选择“有效投注”或“净盈利”作为佣金计算依据，并支持多种佣金计算层数。
  2. 多奖励模式修改：合并返佣设置弹窗，佣金赠送维度保留首充佣金、充值佣金、投注佣金。
  3. 代理公共设置：增加全平台通用的有效人数和返佣上限设置（兼容两种业绩指标）。
  4. 使用说明弹窗：在后台代理模式页面提供模式介绍、公式和示例，帮助运营快速理解配置结果。

有效投注模式说明

模式介绍：有效投注模式按代理下级产生的有效投注计算返佣，代理总业绩越高，命中的返佣比例越高；多级代理按极差返佣比例计算其他佣金。

直属佣金 = 直属下级本人有效投注 × 当前代理返佣比例
其他佣金 = 直属下级总业绩 × (当前代理返佣比例 - 直属下级返佣比例)
本期佣金 = 直属佣金 + 其他佣金
示例：B1本人有效投注500，B2本人有效投注3000，A命中3%返佣比例，则A的直属佣金 = (500 + 3000) × 3% = 105。若B1下级总业绩为3000，B1命中1%，A与B1极差比例为2%，则A从B1获得其他佣金 = 3000 × 2% = 60。A本期佣金 = 105 + 60 = 165。

多奖励模式说明

模式介绍：多奖励模式按多个奖励维度分别计算佣金，后台勾选首充佣金、充值佣金、投注佣金中的哪些维度，前台教程和返佣设置就展示哪些维度。

首充佣金 = 达到首充人数门槛后，发放对应固定奖励
充值佣金 = 对应层级充值金额 × 对应层级返佣比例
投注佣金 = 对应层级投注金额 × 对应层级返佣比例
本期佣金 = 首充佣金 + 充值佣金 + 投注佣金
示例：代理A本期获得首充佣金200、充值佣金38、投注佣金36.4，则A本期佣金 = 200 + 38 + 36.4 = 274.4。若配置为最多两级，则三级及以下不展示、不计算。

净盈利模式说明

模式介绍：净盈利模式按直属会员给平台带来的净盈利计算返佣，公式会根据“净盈利设置”中勾选的扣减项动态调整。

净盈利 = - 直属会员输赢 - 领取优惠 - 充值手续费 - 提现手续费 - 三方游戏统一成本 + 上期结余
上期结余 = 上个周期内直属会员输赢总和，值为负数或0；若大于0，则转化为佣金
直属佣金 = 直属会员净盈利 × 当前代理返佣比例
其他佣金 = 直属下级总净盈利 × 极差返佣比例
本期佣金 = 直属佣金 + 其他佣金
示例：直属会员输赢为-10000，领取优惠500，充值手续费100，提现手续费80，三方游戏统一成本300，上期结余-1000，则净盈利 = -(-10000) - 500 - 100 - 80 - 300 + (-1000) = 8020。若A命中5%返佣比例，则直属佣金 = 8020 × 5% = 401。若某个扣减项在净盈利设置中未勾选，公式中不展示也不参与计算。

3. 核心业务逻辑

3.1. 极差返佣通用逻辑

佣金计算层数（只算一级、最多两级、...、无数级、自定义层数）均采用此逻辑。该逻辑适用于有效投注和净盈利两种业绩指标，唯一区别在于“业绩”的定义。

核心规则

  1. 业绩定义：每个代理的“总业绩”等于其所有下级（不限层级）的自身业绩之和，不包括代理本人的业绩。代理本人的业绩只计入上级的直属业绩。若依据为有效投注：自身业绩 = 会员本人有效投注额。若依据为净盈利：自身业绩 = 会员本人净盈利（定义见3.2）。
  2. 返佣比例：根据代理的“总业绩”，按该模式预设的阶梯确定返佣比例。
  3. 佣金构成：直属佣金 = 所有直属下级本人业绩之和 × 自己的返佣比例；其他佣金（极差佣金） = Σ [ 每个直属下级的总业绩 × (自己的返佣比例 − 该下级的返佣比例) ]；总佣金 = 直属佣金 + 其他佣金。
  4. 无限层级：计算时只关注直接下级，间接下级通过下级的总业绩递归体现。

计算步骤（后序遍历）

  1. 计算每个节点的“总业绩”（递归汇总下级自身业绩）。
  2. 根据每个节点的“总业绩”，确定其“返佣比例”。
  3. 计算每个节点的“总佣金”（直属佣金+极差佣金）。
重要：此极差模式的数学特性保证了所有佣金之和等于根节点总业绩与根节点返佣比例的乘积，实现分配守恒。

3.2. 净盈利定义与计算

适用场景：当代理模式的“佣金计算依据”选择“净盈利”时。

净盈利 指直属会员在结算周期内按平台净盈利口径汇总后的业绩值。公式会根据“净盈利设置”中勾选的扣减项动态调整。

  • 直属会员输赢：直属会员在周期内的输赢汇总。会员输钱时通常为负数，因此公式中使用“- 直属会员输赢”转为平台净盈利。
  • 领取优惠：会员在周期内领取的返水、红包、彩金、活动奖励等。
  • 充值手续费 / 提现手续费：会员充值、提现产生的手续费成本。
  • 三方游戏统一成本：三方游戏或平台统一配置的成本扣减项。
  • 上期结余：上个周期内直属会员输赢总和，值为负数或0；若大于0，则转化为佣金，不作为结余继续累加。

公式

净盈利 = - 直属会员输赢 - 领取优惠 - 充值手续费 - 提现手续费 - 三方游戏统一成本 + 上期结余

代理业绩（总业绩）

  • 每个代理的总业绩 = 其所有下级（不限层级）会员的净盈利之和。
  • 代理本人的净盈利不计入自己的总业绩（仅用于上级的直属业绩计算）。
  • 若某项成本未在“净盈利设置”中勾选，则前台说明、后台说明和实际计算公式中均不展示、不参与计算。

净盈利为负的处理

  • 若某会员净盈利为负（即赢钱或优惠过多），则其贡献的业绩为负数，会降低上级的总业绩。
  • 若代理的“总业绩”为负，则其返佣比例按最低档（或0%），不发放佣金，也不倒扣。

当代理模式为净盈利时，前台代理教程需按净盈利口径展示，整体结构参考前台页面的代理教程：先说明层级关系，再说明净盈利业绩、返佣比例、直属佣金、其他佣金和本期佣金。

2. 层级关系展示A发展B1、B2，B1/B2继续发展C级会员的关系。A的佣金来源包含直属下级贡献和其他下级通过极差产生的贡献。
3. 净盈利业绩展示每个下级会员或代理线的净盈利贡献。例：B1本人净盈利500，B2本人净盈利3000，C1净盈利1000，C2净盈利2000，C3净盈利20000。
4. 返佣比例根据总净盈利命中返佣阶梯。例：A总净盈利26500，对应返佣比例5%；B1总净盈利3000，对应返佣比例2%；B2总净盈利20000，对应返佣比例5%。
5. 佣金计算展示直属佣金、其他佣金、本期佣金。直属佣金 = 直属下级本人净盈利 × A返佣比例；其他佣金 = 直属下级总净盈利 × 极差返佣比例；本期佣金 = 直属佣金 + 其他佣金。
6. 异常说明说明净盈利为负时的处理。会员净盈利为负会降低上级总净盈利；代理总净盈利为负时按最低档或0%处理，不倒扣佣金。

3.3. 返佣上限逻辑

为防止单一代理下级因业绩过高而产生过大佣金支出，平台按结算周期设置每个直属下级单期可贡献给上级的最大佣金金额。

处理规则

  1. 在结算佣金时，对每个直属下级 X 单独计算其贡献给上级 A 的佣金总额 C。C = 来自 X 的直属佣金 + 来自 X 的极差佣金（无论佣金依据是有效投注还是净盈利，均合并计算）。
  2. 获取该结算周期对应的上限值 L（日结/周结/月结上限）。
  3. 若 C ≤ L：C 全额计入上级 A 的佣金。
  4. 若 C > L：只计入 L 金额，超出部分 (C - L) 丢弃，不累积。
  5. 优先级：当总贡献佣金超过上限时，优先限制其他（极差）佣金，再限制直属佣金。即：先发满直属佣金，剩余上限额度若不足以发放极差佣金，则极差佣金部分将被截断。
  6. 适用范围：该上限只针对直属下级，非直属下级贡献不单独设上限。该上限不影响下级自身的佣金计算。

示例（净盈利+上限）

  • 代理A（上级），直属下级B。A返佣比例8%，B返佣比例5%。
  • B本人净盈利50000元，B的总业绩（含下级）为200000元。
  • 计算A从B获得的总佣金：直属佣金 = 50000 × 8% = 4000元；极差佣金 = 200000 × (8% - 5%) = 6000元；下级B贡献总额 = 10000元。
  • 若日结上限为8000元，则A实际获得：直属佣金4000元 + 极差佣金4000元（截断2000元极差部分）。

4. 非功能性需求

  • 性能要求：当代理层级深、人员多时（如百万级节点），佣金结算过程需进行性能优化，避免超时或内存溢出。可采用异步任务、数据库批量计算等方式。
  • 扩展性：佣金计算依据（有效投注、净盈利）和返佣阶梯应设计为可配置，便于未来扩展其他类型（如充值金额、投注笔数等）。
  • 数据一致性：佣金结算涉及金额，需使用数据库事务确保数据的一致性和准确性，避免出现错账。
  • 净盈利数据准确性：净盈利涉及赢/输额、优惠、成本等多个数据源，需保证账变记录精确，建议每日预计算净盈利快照，便于结算时快速汇总。
