举例说明如下：

当前按有效投注完整示例展示：A 可获得直属下级佣金，并按层级范围计算其他下级极差佣金。

假设有效投注<10000 返佣 1%，≥10000 返佣 3%。A 发展了 B1、B2，B1 发展了 C1、C2，B2 发展了 C3。B1 投注 500，B2 投注 3000，C1 投注 1000，C2 投注 2000，C3 投注 20000。

1、极差佣金计算：总佣金 = 直属佣金 + 其他佣金 = 直属业绩×返佣比例 + 各直属下级总业绩×极差返佣比例

2、极差返佣比：当前代理的返佣比例与直属下级的返佣比例之差。A 总业绩 26500 对应 3%，B1 总业绩 3000 对应 1%，极差 = 3%−1% = 2%；B2 总业绩 20000 对应 3%，极差 = 0%。

3、A 的计算：直属佣金 = 3500×3% = 105；其他佣金 = 3000×2% + 20000×0% = 60；本期佣金 = 105+60 = 165。

B1 发展 C1、C2，C1 投注 1000，C2 投注 2000，C1/C2 均无下级。

B1 的计算：直属佣金 = 3000×1% = 30；其他佣金 = 0；本期佣金 = 30。

B2 发展 C3，C3 投注 20000，C3 无下级。

B2 的计算：直属佣金 = 20000×3% = 600；其他佣金 = 0；本期佣金 = 600。

4、补充：无限极差代理可横向 + 纵向无限发展，本例只取 2 层结构作为示意。

净盈利教程

🧔A
直属净盈利=8000+12000=20000
直属佣金=20000×5%=1000
其他佣金=40000×(5%−3%)=800
三级极差=18000×(5%−2%)=540
本期佣金=2340
代理层级结构
直属下级 B1 净盈利 8000
佣金比例 5%
贡献A直属佣金 400
直属下级 B2 净盈利 12000
佣金比例 5%
贡献A直属佣金 600
↓↓↓
间接下级 C1 净盈利 22000
极差比例 2%
贡献A极差佣金 440
间接下级 C2 净盈利 18000
极差比例 2%
贡献A极差佣金 360
间接下级 C3 净盈利 18000
极差比例 3%
贡献A极差佣金 540
↓
N 级下级 无数级时，可继续向下计算范围内的净盈利极差佣金。
佣金计算
净盈利公式 总输额 − 总赢额 − 优惠 − 成本
直属佣金 20000 × 5% = 1000
其他佣金 40000 × (5%−3%) = 800
三级极差 18000 × (5%−2%) = 540
本期总佣金 1000 + 800 + 540 = 2340

净盈利模式说明

净盈利 = 会员总输额 − 会员总赢额 − 优惠奖励 − 平台成本。代理按下级在结算周期内产生的净盈利作为业绩。

当前按三级示例展示：A 可获得直属 B 层的直属佣金，也可获得 C 层产生的极差佣金。

示例：A 的直属下级 B1、B2 产生净盈利 20000，A 返佣比例 5%，直属佣金 1000。

二级极差：B 层下级总净盈利 40000，比例差 2%，其他佣金 800。

三级极差：第三级净盈利 18000，比例差 3%，极差佣金 540。

本期佣金：1000 + 800 + 540 = 2340。
