前台推广页面需求文档

用于说明前台“推广赚钱”页面的导航、推广分享、代理教程、返佣比例与调试联动规则。

版本：V1.0 日期：2026-05-20 状态：原型需求
1. 功能概述 2. 有效投注模式 3. 多奖励模式改造 4. 净盈利模式新增 5. 返佣比例展示 6. 显示与交互规则 7. 验收标准

1. 功能概述

本需求文档仅描述前台推广页面中与代理模式新增/改造相关的内容，重点覆盖代理教程与返佣比例展示。

本次前台改造重点为：保留有效投注一级原功能；改造多奖励模式教程与返佣比例；新增净盈利模式教程与返佣比例展示。

模块处理方式说明
有效投注模式一级为原功能，不需要处理最多两级及以上可参考现有极差返佣教程展示，前台保持有效投注口径。
多奖励模式需要改造根据后台佣金赠送维度和计算层数，动态展示教程、表格、文字和返佣比例。
净盈利模式新增，需要改造新增净盈利口径教程、净盈利公式说明、佣金计算示例和返佣比例表。

2. 有效投注模式

2.1 处理范围

有效投注模式中的“只算一级”为原有功能，本次前台需求不需要对一级功能做业务改造。页面如需展示一级示例，仅用于保持原有说明完整性，不改变原计算口径。

2.2 多级展示说明

内容展示要求
层级关系展示 A 发展 B1、B2，B1/B2 继续发展 C 级下级，并支持 N 级说明。
业绩字段统一使用“有效投注”口径，不出现净盈利、充值金额等混用字段。
佣金构成展示直属佣金、其他佣金、本期佣金。
极差说明说明当前代理返佣比例与直属下级返佣比例的差值，即极差返佣比例。

2.3 示例文案要求

  • 文案需说明“直属业绩 = 直属下级本人有效投注之和”。
  • 文案需说明“其他佣金 = 直属下级总业绩 × 极差返佣比例”。
  • 只算一级时，间接下级不参与当前代理佣金计算。

3. 多奖励模式改造

3.1 改造目标

多奖励模式前台需根据后台配置的佣金赠送维度和佣金计算层数，动态展示对应教程内容。该模式不包含净盈利佣金。

配置项支持值前台影响
佣金计算层数最多两级、最多三级最多两级时隐藏三级节点、三级表格列、三级说明文案。
佣金赠送维度首充佣金、充值佣金、投注佣金前台仅展示已启用维度对应的教程、表格和返佣比例。

3.2 教程区域

模块展示要求
顶部佣金汇总按已启用维度展示首充佣金、充值佣金、投注佣金及本期佣金合计。
层级流程图最多三级时展示 B/C/D 三层；最多两级时展示 B/C 两层。
节点信息每个节点仅展示已启用维度的佣金信息，未启用维度不展示。
佣金计算按启用维度分别展示计算结果，并汇总本期总佣金。
说明文案文案需动态说明当前启用的佣金维度和层级范围。

3.3 返佣比例区域

  • 返佣比例页面顶部展示已启用维度按钮，如“首次充值佣金、充值佣金、投注佣金”。
  • 切换按钮后展示对应维度的返佣比例表。
  • 选择最多两级时，充值佣金和投注佣金表格不展示三级返佣列。
  • 至少保留一个佣金维度；如果后台未返回任何维度，前台需给出兜底提示。

4. 净盈利模式新增

4.1 新增目标

新增净盈利模式前台教程和返佣比例展示。净盈利模式需完全使用净盈利口径，不得复用有效投注字段文案。

4.2 净盈利定义

净盈利指会员在结算周期内产生的：总输额 - 总赢额 - 优惠金额 - 平台成本。

字段说明
总输额会员周期内游戏下注输掉的金额。
总赢额会员周期内游戏赢得的金额。
优惠金额会员获得的返水、红包、彩金、活动奖励等。
平台成本平台按配置分摊的成本，默认为 0。

4.3 教程区域

模块展示要求
模式说明说明当前代理模式按净盈利计算佣金，并展示净盈利公式。
层级关系展示 A、B、C、N 级代理关系，结构参考有效投注多级教程。
业绩字段节点内展示“净盈利”贡献金额，不展示有效投注字段。
返佣比例根据代理总净盈利命中对应返佣比例。
佣金计算展示直属佣金、其他佣金、本期佣金。
异常说明净盈利为负会降低上级总净盈利；代理总净盈利为负时按最低档或 0% 处理，不倒扣。

4.4 返佣比例区域

  • 净盈利返佣比例表不展示场馆分类。
  • 表格字段为：等级、总净盈利、佣金。
  • 展示样式参考有效投注返佣比例表，但字段文案需替换为净盈利口径。

5. 返佣比例展示

返佣比例页面只描述本次新增/改造模式相关展示，不改变其他已有页面入口。

模式是否处理展示要求
有效投注原功能保留按原有效投注场馆分类和返佣比例表展示。
多奖励模式需要改造按启用维度动态展示首充、充值、投注返佣比例。
净盈利模式新增展示净盈利返佣比例，不展示场馆分类。

6. 显示与交互规则

  1. 页面主容器宽度使用手机尺寸，当前原型为 390px，小屏时自适应 100vw。
  2. 教程中的流程图、表格、说明文案需与当前代理模式一致。
  3. 多奖励模式根据后台启用维度动态展示，不展示未启用维度。
  4. 净盈利模式所有字段和说明统一使用净盈利口径。
  5. 页面文字需避免翻译腔，公式和示例要与当前模式一致。
说明：当前文档聚焦代理教程与返佣比例的前台展示要求，正式接入时需以后端代理模式配置为准。

7. 验收标准

  • 有效投注一级保持原功能，不因本次需求改变计算逻辑。
  • 多奖励模式可根据佣金维度和层数展示对应教程内容和返佣比例。
  • 净盈利模式可展示净盈利公式、层级关系、佣金计算和返佣比例。
  • 多奖励模式不出现净盈利佣金维度。
  • 净盈利模式不出现有效投注口径混用。
  • 移动端宽度下页面无明显横向溢出，表格和卡片内容可读。
